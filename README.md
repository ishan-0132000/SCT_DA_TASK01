# Superstore Sales Dashboard | Excel Data Analytics

A professional Excel dashboard designed to analyze Superstore sales data, identify sales patterns, compare regional performance, and transform raw data into meaningful business insights.

## Project Overview

This project focuses on analyzing a Superstore sales dataset containing **9,800 records and 18 columns**.

Using Microsoft Excel, I organized the raw dataset, created formula-driven summaries, and developed a visually structured dashboard to make sales performance easier to understand.

The dashboard provides an overview of revenue, transaction volume, category performance, monthly trends, and regional sales distribution.

## Key Features

- **Sales Overview:** Total sales, total transactions, and average sales per record.
- **Category Analysis:** Compare sales performance across product categories.
- **Monthly Sales Trends:** Understand how sales change over time.
- **Regional Analysis:** Compare sales across different regions.
- **Category Mix:** Visualize the contribution of each category.
- **Data Cleaning:** Prepare and organize raw sales data.
- **Data Visualization:** Present business metrics through charts and KPI cards.

## Dataset

**Dataset:** Superstore Sales Dataset

- Total Records: 9,800
- Total Columns: 18
- Format: CSV

The dataset includes order information, customer details, product categories, regions, order dates, and sales figures.

## Important Data Limitation

The supplied dataset does not contain a Profit or Cost column. Therefore, this dashboard focuses on sales performance and does not claim to calculate actual profit.
